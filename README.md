# File Sharing Web Application

## Overview
This is a simple file-sharing web application where users can upload, and download their files. It is built using **Node.js**, **Express**, and **MongoDB**.

## Features
- **File Upload**: Users can upload files with a `.txt` extension.
- **File List**: Displays all uploaded files.
- **Download**: Users can download any uploaded file.


## Technologies Used
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Frontend**: HTML, CSS, JavaScript (Vanilla)
